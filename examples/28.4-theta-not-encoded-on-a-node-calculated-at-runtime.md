## 28.4 theta Not Encoded on a Node, Calculated at Runtime

A node with no orientation defined in the Base LIF above, illustrated by an order where the fleet control system calculates one at runtime from the direction of the incoming edge.

Order (nodes array, orientation calculated from the direction of N1-N2):
```json
{
    "nodes": [
        {
            "nodeId": "N2",
            "sequenceId": 4,
            "released": true,
            "actions": [],
            "nodePosition": {
                "x": 11.0,
                "y": 0.0,
                "theta": 1.5
            }
        }
    ]
}
```
