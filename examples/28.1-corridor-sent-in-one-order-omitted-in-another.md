## 28.1 Corridor Sent in One Order, Omitted in Another

An edge (straight line) with an optional corridor of up to 0.5 m to each side, illustrated by two orders valid against the Base LIF above: one requests a narrower corridor for a wider load, the other leaves it out for plain travel with no lateral deviation.

Order A (edges array, corridor requested):
```json
{
    "edges": [
        {
            "edgeId": "N1-N2",
            "sequenceId": 2,
            "released": true,
            "actions": [],
            "corridor": {
                "leftWidth": 0.4,
                "rightWidth": 0.4
            }
        }
    ]
}
```

Order B (edges array, corridor omitted):
```json
{
    "edges": [
        {
            "edgeId": "N1-N2",
            "sequenceId": 2,
            "released": true,
            "actions": []
        }
    ]
}
```
