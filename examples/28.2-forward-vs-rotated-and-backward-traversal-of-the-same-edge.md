## 28.2 Forward vs. Rotated-and-Backward Traversal of the Same Edge

An edge (straight line) that permits travel both forward and backward, requiring the mobile robot to reach the right orientation before entering it, illustrated by two orders valid against the Base LIF above: one traverses forward without rotating, the other rotates first and traverses backward.

Order A (nodes and edges array, drive forward, no rotation needed):
```json
{
    "nodes": [
        {
            "nodeId": "N1",
            "sequenceId": 0,
            "released": true,
            "actions": [],
            "nodePosition": {
                "x": 0.0,
                "y": 0.0,
                "theta": 0.0
            }
        }
    ],
    "edges": [
        {
            "edgeId": "N1-N2",
            "sequenceId": 2,
            "released": true,
            "actions": [],
            "orientation": 0.0
        }
    ]
}
```
